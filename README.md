# Real Estate Lead Organizer

Simple local-first lead organizer web app for real estate leads, labels, appointments, calendar view, and reminders.

## How to host on GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html` to the repository root.
3. Go to Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select `main` branch and `/root`, then Save.
6. Open the GitHub Pages URL after deployment.

## Note

This version stores data in the browser's local storage. Use Export Backup regularly. Cloud sync can be added later with Google Sheets or Firebase.
